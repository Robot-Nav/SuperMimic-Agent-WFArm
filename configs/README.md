# Example configurations

- `examples/wf_train.json`: folded-zero whole-body training starting point, using external private robot assets.
- `examples/fixed_arm_smoke.json`: small six-axis baseline integration run on CPU.

The examples do not include robot geometry, calibration, learned weights or
historical experiment paths. Configure a fresh output directory and keep
train/validation/test requests separate. Example budgets are not evidence of task success.

See [English](../README.md) or [中文](../README_CN.md) for setup and commands.
